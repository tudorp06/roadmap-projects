# Unit converter

A small browser-based converter for length, weight, and temperature, with a pencil-style UI using the Caveat typeface.

## Run

Open `index.html` in your browser. The page loads its typeface from Google Fonts.

## What I practiced

I practiced DOM events, switching the available units, parsing input, base-unit conversion, temperature formulas, and styling a small interface.

## Notes

This is a learning implementation with a limited set of units. The public copy corrects the Celsius return and the ounce/pound factors.
